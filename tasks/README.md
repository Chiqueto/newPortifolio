# Portfolio CMS Migration

## Objetivo Geral
Migrar os dados hardcoded/mockados do portfólio para um CMS próprio usando o Supabase, permitindo gerenciamento dinâmico do conteúdo através de um painel de administração.

## Ordem de Execução
As tasks devem ser executadas sequencialmente. Uma task só começa após a anterior estar concluída.

1. **TASK 01**: Repository and Supabase Foundation
2. **TASK 02**: Admin Auth and CMS
3. **TASK 03**: Public Data Migration

## Dependências
- Supabase (PostgreSQL, Auth, Storage)
- Next.js
- Tailwind CSS
